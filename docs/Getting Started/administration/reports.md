TappCash provides two categories of reports for admin roles: **client reports** scoped to individual client activity, and **general system reports** that aggregate activity across the branch or organization.

---

## Report Types

| Report Type           | Description                                                                                   |
|-----------------------|-----------------------------------------------------------------------------------------------|
| **Client Reports**    | Activity reports scoped to a specific Individual or Business Owner client — transactions, transfers, account history |
| **General System Reports** | Aggregated reports across the branch or organization — summary views for management and compliance |

---

## Access by Role

All admin roles with client portfolio access can view reports. Scope varies by role:

| Role                    | Client Reports    | General System Reports | Scope              |
|-------------------------|:-----------------:|:----------------------:|--------------------|
| **Root Advisor**        | ✓                 | ✓                      | All branches       |
| **Head Branch Manager** | ✓                 | ✓                      | All managed branches |
| **Branch Manager**      | ✓                 | ✓                      | Assigned branch    |
| **Advisor**             | ✓                 | ✓                      | Own portfolio      |

---

## Report Availability

Reports are available for both client types:

- **Individual clients** — transaction history, transfer history, account statements, balance trends
- **Business Owner clients** — business account activity, operator transaction history, transfer reports

> Account statements (monthly PDF download per account) are also accessible to clients directly. See [Account Statements](../individual-user/account-statements) for the client-facing endpoint.
